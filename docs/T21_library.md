# T21 — библиотека GIF из папки, миниатюра последней отправки, правка часов

Ветка: `feature/t21-library` (от `master` после слияния T20). Правила — AGENTS.md. Ядро `s360_lcd.py`, `monitor.py` и протокол не менять.
Владелец положил в корень готовый модуль `thumbs.py` (список GIF/MP4 в папке и миниатюры 120×160 с кэшем, проверен тестом). Не правь его, используй:
`thumbs.list_media(folder, limit)`, `thumbs.ensure_thumb(src, cache_dir)`. Строку копирования `thumbs.py` в `install.sh` добавь (больше ничего в install.sh не менять).

## 1. «Мониторинг»: картинка последней отправки
Карточку «Последнее на экране» переименовать в «Последнее отправленное» (мы не знаем, что на экране сейчас). В карточке слева миниатюра, справа имя файла,
время и «Отправлено». Миниатюра: при успешной отправке скопировать PNG текущего предпросмотра (тот, что построен с `viewer=True`) в
`$XDG_STATE_HOME/s360-lcd/last_sent.png` (по умолчанию `~/.local/state/s360-lcd/`). Если файла нет — только текст. Рамка по пропорциям самой картинки
(вертикальная при положении 0°/180°, горизонтальная при 90°/270°).

## 2. «LCD-дисплей»: библиотека из папки
В правой карточке под «Масштаб» и «Положение экрана» блок «Библиотека»: заголовок, кнопка «Папка…» (`QFileDialog.getExistingDirectory`), путь (с обрезкой по ширине),
ниже сетка превью (например, `QListWidget` в режиме иконок, иконка 120×160, подпись — имя файла, прокрутка). Блок занимает всё свободное место карточки.
- Показываются только GIF и MP4 из выбранной папки без вложенных (`thumbs.list_media`); не больше 100, при превышении строка «Показаны первые 100».
- Клик по превью — то же, что «Выбрать файл»: обновляет большой предпросмотр и имя файла; выбранный элемент подсвечен и синхронизируется с «Выбрать файл».
  Сам клик ничего не отправляет: отправка только главной кнопкой с подтверждением.
- Миниатюры создаются в ФОНОВОМ потоке по одной (`thumbs.ensure_thumb`, кэш `~/.cache/s360-control/thumbs`); пока не готова — заглушка; не читается — заглушка
  и подсказка «не открывается». Интерфейс не должен подвисать при открытии папки со ста файлами. Фоновый поток не должен трогать `core.ENC` и вызывать
  `core.preview_png`/`core.build_vf` (общие настройки, гонка): только `thumbs.ensure_thumb`.
- Папка запоминается в `settings["gif_dir"]` (ключ добавить в настройки интерфейса без правки ядра) и открывается при следующем запуске, если существует.
  Нет папки — одна строка «Выбери папку с GIF — здесь появятся превью» и кнопка.

## 3. «Часы»: сдвиг текста
В карточке «Часы» заголовок и строка со временем «уехали вверх» (заголовок группы режется верхней границей). Поправить отступы/компоновку так,
чтобы заголовок целиком внутри карточки, время и подписи выровнены; проверить при масштабе 100% и 150% (`QT_SCALE_FACTOR=1.5`), стили 1–5 без изменений.

## Проверки
Один новый `tools/check_t21.py` (до 10 проверок): в папке со смесью файлов видны только GIF/MP4; клик по превью выбирает файл и ничего не отправляет;
папка сохраняется в настройках и восстанавливается; превью создаются в фоне (в момент открытия окно уже отвечает, заглушки на месте);
`core.ENC` не меняется от фонового потока; успешная отправка (подменить) сохраняет `last_sent.png`, а карточка мониторинга её показывает;
заголовок карточки «Часы» целиком внутри карточки; **для каждого локального модуля, который импортирует `s360_gui.py` (theme, monitor, thumbs, s360_lcd),
в `install.sh` есть строка его копирования** (чтобы не повторилась ошибка «No module named …» после установки). Запустить `python3 thumbs.py`,
`python3 monitor.py selftest` и ВСЕ `tools/check_t*.py` без флагов пропуска, перечислить команды. Не запускать install.sh, не вливать в master,
на устройство ничего не отправлять. Один коммит и короткий отчёт: что изменено, что проверить в Hyprland.
