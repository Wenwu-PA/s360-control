# T18 — один поворот на LCD, понятное охлаждение без «Подробностей»

Ветка: `feature/t18-simplify` (от `feature/t17-screen-position`). Правила — AGENTS.md. Ядро и протокол не менять.
Решения владельца по ручной проверке T17.

## 1. LCD: один элемент поворота
- Убрать список «Поворот картинки». Остаётся одна строка кнопок «Положение экрана» 0° / 90° / 180° / 270° (как сейчас).
  Она управляет и предпросмотром (рамка 3:4 при 0°/180°, 4:3 при 90°/270°, картинка внутри прямая), и отправляемым файлом
  (`core.ENC["orient"]`). `core.ENC["rotate"]` из интерфейса всегда 0 (в CLI `--rotate` остаётся).
- Подпись под рамкой: «240 × 320 · положение 90°» (при 90°/270° размер 320 × 240). Слов «поворот картинки» в интерфейсе больше нет.
- Загрузка настроек: если в `settings.json` `rotate` не 0, при чтении трактовать как 0 (чтобы не осталось скрытого второго поворота).
- Диалог подтверждения: строка «Положение экрана: 90°», если не 0°. Часы: прежнее предупреждение при положении не 0°.

## 2. Охлаждение: числа точек
Поля с числами под большим графиком (Точка 1…4: °C и %) на экране владельца ПУСТЫЕ, хотя проверки проходят. Исправить так, чтобы значения было видно.
- Причину искать в стилях: цвет текста полей, ширина/отступы, не скрывает ли кнопка-стрелка текст у QSpinBox/QDoubleSpinBox. Если спинбоксы не
  лечатся за две попытки — заменить на QLineEdit с QIntValidator (стрелки клавиатуры ±1, Enter применяет, клик по полю выделяет текст).
- Тест «текст виден»: для каждого такого поля `widget.grab().toImage()` и проверка, что в области есть пиксели светлее фона с контрастом не
  меньше 4,5:1 (тест обязан падать на пустом поле). Не опираться на `widget.text()`.
- Значения обновляются при выборе другого графика и при перетаскивании точки, и наоборот.

## 3. Охлаждение: убрать «Подробности»
- Удалить кнопку и весь блок «Подробности», а также строки «Контроллер охлаждения подключён», «Последний отправленный режим…», «RPM и
  температура жидкости недоступны…», «Поведение после остановки…». Технические подробности остаются только в README.
- Автозапуск — всегда включён, без галочки: «Применить» делает `systemctl --user enable` + запуск/перезапуск сервиса (как раньше, только по кнопке).
- В нижней полосе: плашка состояния (Работает / Остановлен / Ошибка) и одна строка. При ошибке сервиса — её короткий текст
  (последняя строка журнала) и совет `./install.sh`, если установленная копия устарела. Рядом с плашкой маленькая кнопка «Остановить»,
  видна только когда сервис работает: останавливает сервис и отключает автозапуск (следующее «Применить» включит снова).
- Для «Свой профиль» добавить только кнопку «Сбросить до стандартных»: возвращает видимые три кривые к `core.DEFAULT_CURVES`;
  radiator2/radiator3 не трогать; ничего не отправлять на устройство, значения сохраняются как локально изменённые.
