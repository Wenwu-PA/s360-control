# T17 — Положение экрана, градусы в предпросмотре, правки охлаждения

Ветка: `feature/t17-screen-position` (от `feature/t16-lcd-fixes`). Правила — AGENTS.md. Ядро и протокол не менять.
Перед задачей владелец применил к ядру `apply_screen_position.py`: в `s360_lcd.py` появились
`core.ENC["orient"]` (0/90/180/270), `core.build_vf(..., viewer=False)`, `core.preview_png(src, dst, viewer=False)`
и ключ настроек `screen_pos`. Не переписывай их, только используй.

## Два разных поворота (в интерфейсе называть так)
- **Поворот картинки** (`ENC["rotate"]`) — крутит само изображение. Уже работает.
- **Положение экрана** (`ENC["orient"]`) — как физически повёрнут экран водянки (по часовой). Программное: картинка в файле
  автоматически поворачивается обратно, чтобы на повёрнутом экране выглядеть прямо. Команда поворота экрана (cmd 1a) НЕ отправляется.

## Что сделать
1. **LCD: «Положение экрана».** Строка из четырёх кнопок 0° / 90° / 180° / 270° (выбранная выделена) в карточке файла рядом с «Поворот картинки».
   Подсказка: «Как повёрнут экран водянки. Картинка повернётся сама, чтобы выглядеть прямо». Значение хранится в `settings["screen_pos"]`,
   при отправке и в предпросмотре выставляется `core.ENC["orient"]`.
2. **Предпросмотр.** Строить через `core.preview_png(..., viewer=True)`. Рамка предпросмотра: при 0°/180° вертикальная 3:4 (240×320),
   при 90°/270° горизонтальная 4:3 (320×240) — «экранчик» поворачивается горизонтально, картинка внутри прямая. Рамку не поворачивать виджетом.
3. **Подпись** под рамкой всегда с градусами: «240 × 320 · положение 0° · поворот картинки 0°» (размер меняется на 320 × 240 при 90°/270°).
   Вместо «—» вместо имени файла — «файл не выбран».
4. **Отправка.** Файл строится как раньше через `build_vf(viewer=False)` (всегда 240×320). В диалоге подтверждения добавить строку
   «Положение экрана: 90°», если оно не 0°.
5. **Часы.** При положении не 0° показать одну строку: «Часы пока не поворачиваются под положение экрана». Остальное без изменений.
6. **Охлаждение (баг).** Поля чисел под большим графиком пустые — показывать значения («51 °C» и «13 %»), проверить цвет текста и загрузку значений
   при выборе малого графика (на скриншоте большим был «Вентилятор водоблока»).
7. **Охлаждение: «Запускать при входе в систему».** По умолчанию включено; действует только при нажатии «Применить», снять галочку можно.
