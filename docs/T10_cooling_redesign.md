# T10 — Охлаждение: проще и понятнее (заменяет прежнюю T10)

Макет: https://claude.ai/artifact/E85ZeTaD99KAFQbWfGHjVA (два экрана). Экспортируй их в PNG и положи в `docs/design/cooling-custom.png` и `docs/design/cooling-preset.png`.
Ветка: `feature/t10-cooling`. Правила — AGENTS.md. Протокол и ядро (`s360_lcd.py`) не менять.

## Что меняется и почему
1. **Три кривые, не пять.** В MSI Center три регулировки: вентилятор радиатора (все три вентилятора вместе), вентилятор водоблока, помпа. В GUI показывать три графика: `radiator1`, `waterblock`, `pump`. Каналы `radiator2` и `radiator3` в GUI не показывать и **не менять**: в JSON они хранятся и уходят в водянку как есть (так делает MSI Center: в захвате 7 при правке радиатора менялся только блок 0). Не копировать радиатор 1 в каналы 2–3.
2. **Язык попроще.** Вместо технических фраз — короткие. «Передача температуры CPU / сервис» → «Температура процессора передаётся — охлаждение работает / остановлено». Режимы: Тихий «Тише всего», Сбалансированный «На каждый день», Игровой «Максимум охлаждения», Свой профиль «Настрой сам». Подробности (hidraw, d0 40/41, пути файлов) — только в свёрнутом блоке «Подробности».
3. **Одна главная кнопка «Применить».** Она сохраняет профиль (если свой), отправляет режим и запускает сервис. Рядом «Сохранить» (только локально). Убрать отдельные «Применить режим» и «Запустить». Индикатор «Изменения не сохранены».
4. **Графики:** три карточки в ряд (на узком окне — по одной в столбец). Точки перетаскиваются мышью, при перетаскивании подсказка «48° · 21%». Под графиком четыре «чипа» `48° · 21%`, по клику редактируются числом. Для помпы — серая зона «ниже 60% нельзя». Проверка только `core.validate_curves`, без новых ограничений; ошибки — понятным текстом, введённое молча не менять.
5. **Готовый режим (Тихий/Сбалансированный/Игровой):** показать три карточки-заглушки «Кривую задаёт сама водянка — программа её не видит» (кривые прошивки неизвестны; их не выдумывать).

## Исправить (баг)
Режим «Свой профиль»: GUI не показывает, что сервис работает, и настройки не применяются; готовые режимы работают.
- GUI показывает честное состояние сервиса: работает / запускается / **ошибка** (с последней строкой `journalctl --user -u s360-feed.service -n 1`).
- Если файла кривых нет или он не проходит `validate_curves`, перед применением показать понятное сообщение, не запускать сервис.
- Не менять сервис и протокол. Возможная причина — установленная копия `s360-lcd` старее (владелец проверит и выполнит `./install.sh` сам).

## Документы
В `docs/PROTOCOL_VERIFIED.md` исправить: блоки 1–2 (`radiator2`, `radiator3`) — не вентиляторы радиатора, а неиспользуемые каналы (в старых захватах их обороты нулевые; MSI показывает один график радиатора). Назвать их в тексте «служебные».
