# Что неизвестно и какие данные нужны

Захваты: Windows, USBPcap, MSI Center; одна запись = одно действие; сохранить исходный pcap с дескрипторами
(0DB0:9BA6 и 0DB0:6A05), UTC-время нажатия, видимый результат (фото экрана/RPM в MSI Center).

| Вопрос | Что нужно |
|---|---|
| Кастомный профиль охлаждения (Customize: кривые Radiator / Pump / Water Block) | 3 записи: (1) Customize + известная кривая A (записать все точки), (2) кривая B с одной изменённой точкой, (3) изменена только кривая Pump. Сравнить `d0 40/41` — по diff определить, где температуры и обороты |
| Яркость, Direction (поворот экрана), тумблер LCD Display | по записи на действие; в MSI Center яркость/направление ещё и сохраняются во флеш экрана — не гонять циклом |
| Режимы экрана: Hardware Monitor, System Clock, Live Weather, Customize Banner | по записи на переключение режима |
| Silent / Balance / Game на этом устройстве | по записи на режим: сверить байт режима (смещения 2/10/18/26/34) и что шлёт MSI Center |
| Что делает охлаждение, если передача температуры CPU (`d0 85`) остановлена | тест с MSI Center в виртуалке, наблюдая обороты |
| Предел длины/кадров/fps анимации | проверено: 20/3, 10, 15 fps, до ~2,5 с (37 кадров, 146 КБ); дальше — ступенчатые тесты владельцем |
| Поворот экрана (`cmd 1a`) и слот R1 для 90/270 | взято из статического анализа DLL, в захватах нет |
| Чтение RPM / температуры жидкости | сопоставить `d0 31` с показаниями MSI Center по времени |
