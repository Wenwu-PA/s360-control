# Что неизвестно и какие данные нужны

Захваты: Windows, USBPcap, **хаб 1**, перед серией проверять `python check_capture.py файл`.

| Вопрос | Что нужно |
|---|---|
| Hardware Monitor (смысл байтов `cmd 50`) | запись с известным набором галочек (записать, какие стоят) |
| GI Mode (кулер, «Smart») | запись переключения на GI Mode |
| Стили часов 2–5 | по записи на стиль |
| Direction 90° и 270°, слот R1 | запись: поворот на 90 и 270 |
| Что делает охлаждение, если передача температуры CPU (`d0 85`) остановлена | тест с наблюдением оборотов (MSI Center в виртуалке) |
| Блоки 1-2 = радиаторные вентиляторы 2 и 3 | запись: Customize, радиатор → вкладка 2, потом 3, по одной точке |
| Предел точек/оборотов в Customize (у водоблока стандартный максимум 53%) | чтение лимитов из MSI Center: попробовать выставить >53% у водоблока и записать |
| Чтение RPM/температуры жидкости | сопоставить ответы `d0 31` с показаниями MSI Center по времени |
| Предел длины/кадров/fps анимации | проверено: 20/3, 10, 15 fps, до ~2,5 с на наших файлах; MSI загрузил файл 664414 байт |

## Не планируется (решение владельца)
Режимы экрана «Погода» (Live Weather) и «Баннер» (Customize Banner) — не делаем, записи для них не нужны.
