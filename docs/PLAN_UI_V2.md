# План: внешний вид по дизайну v2 (T12–T16)

Источник истины: `docs/DESIGN_SPEC.md` и `docs/design/v2/`. Правила — AGENTS.md. Одна задача за раз, ветка `feature/t12-...`.
Каждая задача заканчивается отдельным коммитом в своей ветке. Если добавляешь python-модуль — добавь строку его копирования
в install.sh (больше ничего в install.sh не менять). Логику, ядро и протокол не менять; существующие функции и подтверждения сохранить. Тесты: обновить существующие `tools/check_t*.py`,
один новый `check_t*` на задачу (до ~10 проверок), не больше. Две попытки исправления, потом стоп и отчёт.

**T12. Основа.** Модуль `theme.py` с токенами из DESIGN_SPEC (цвета, шрифты, отступы, радиусы) и генератором QSS. Каркас окна: заголовок,
вкладки, нижняя полоса (плашка + строка + главное действие). Шрифты Inter → Noto Sans. Старые страницы пока внутри нового каркаса.

**T13. Обзор и состояния.** Экраны 01, 06, 07, 12: обзор, нет доступа к USB, устройство не найдено, первый запуск. Кнопка «Проверить подключение».

**T14. LCD (v2.1).** Экраны LCD по `docs/DESIGN_SPEC.md`, раздел «v2.1: LCD» (там описаны «Изображение» и «Часы» словами) и макетам
`lcd-v2.1.html (экран «Изображение»)`, `тот же файл, экран «Часы»`. Логика отправки, подтверждения, яркость «только по Применить» — прежние.

**T15. Охлаждение.** Убрать лишний подзаголовок «Охлаждение» над карточками режимов и одинокую кнопку «▸» под графиками. Экраны 04, 05, 13: готовый режим (прочерки, без выдуманных кривых), свой профиль (большой график + два малых;
в узком окне вкладки). Зажим помпы ≥ 60% в координатах мыши и поле ввода без сообщения. Каналы radiator2/3 не показывать и не менять.

**T16. Узкое окно и финиш.** Экран 13 для всех страниц, High DPI, фокус с клавиатуры, обновить README и PLAN.

## Что нужно от владельца
Кадры 03 (LCD/Часы) и 09 (идёт отправка) — если есть; если нет, делать по компонентам из `11-components-and-states.png`.
