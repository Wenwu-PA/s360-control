# T22 — сдвиг картинки мышью на предпросмотре, превью на «Мониторинге»

Ветка: `feature/t22-pan` (от `master` после слияния T21). Правила — AGENTS.md. Протокол не менять.
Перед задачей владелец применил к ядру `apply_pan_support.py` и положил в корень `pan.py` и обновлённый `thumbs.py`. Теперь в ядре есть
`core.build_vf(..., enc=None)` и `core.preview_png(src, dst, viewer=False, enc=None)`: параметр `enc` — словарь настроек поверх `core.ENC`,
сам `ENC` он не меняет. Режим «Вписать» учитывает `focus_x`/`focus_y` (положение картинки в кадре, 0.5 = по центру — как было).
`pan.py` — готовая математика сдвига (проверена по реальным рендерам: смещение совпало до пикселя), `thumbs.media_size(path)` — размер исходника.
Не правь `pan.py`, `thumbs.py`, ядро; используй: `pan.span`, `pan.can_pan`, `pan.drag`, `thumbs.media_size`, `core.preview_png(..., enc=...)`.

## 1. Сдвиг перетаскиванием на предпросмотре (вкладка LCD)
- Зажал кнопку мыши на большом предпросмотре и тянешь — картинка «едет под пальцем». «Заполнить»: двигается окно обрезки (по тем осям, где картинка выходит за кадр:
  у альбомной — влево/вправо, у высокой — вверх/вниз). «Вписать»: картинка двигается по свободному месту в кадре (у альбомной в вертикальном кадре — вверх/вниз,
  у высокой — влево/вправо). «Растянуть»: сдвига нет.
- Формулы только из `pan.drag(mode, fx, fy, dx, dy, sw, sh, vw, vh)`: dx, dy — смещение мыши в пикселях КАДРА (экранные пиксели × vw / ширина виджета предпросмотра),
  sw, sh — размер исходника (`thumbs.media_size`, запросить один раз при выборе файла), vw×vh — кадр зрителя: 240×320 при положении 0°/180°, 320×240 при 90°/270°.
  Результат записать в `focus_x`/`focus_y` (в настройки интерфейса и в `enc`).
- Курсор: открытая ладонь, если сдвиг возможен (`pan.can_pan`), закрытая во время перетаскивания, обычный — если нет. Двойной клик по предпросмотру — вернуть по центру (0.5, 0.5).
- Обновление картинки во время перетаскивания: НЕ в потоке интерфейса. Отдельный рабочий поток, один запуск ffmpeg одновременно, «последний запрос побеждает»
  (если пришли новые значения, пока шёл рендер, после него запустить рендер с последними). Рендер: `core.preview_png(src, dst, viewer=True, enc={...scale, focus_x, focus_y, orient, ...})`
  с полным набором текущих настроек в `enc`, без записи в `core.ENC` из этого потока. При отпускании — финальный рендер.
- При выборе нового файла и при смене режима «Заполнить»/«Вписать» — focus сбрасывать в (0.5, 0.5). Положение сохраняется в настройках, как сейчас.
- Отправка использует те же `focus_x`/`focus_y` (то, что видно в предпросмотре, то и уйдёт на экран). Подсказка в предпросмотре — одна короткая строка: «Тяни, чтобы сдвинуть» (показывать, только если сдвиг возможен).

## 2. «Мониторинг»: превью последней отправки не видно
Миниатюра сохраняется только при успешной отправке ПОСЛЕ T21, поэтому у старых записей картинки нет. Исправить:
- при успешной отправке сохранять в настройках полный путь файла (`last_file_path`) вместе с именем;
- если `last_sent.png` нет, но файл по пути существует — построить миниатюру через `thumbs.ensure_thumb` в фоне и показать; нет файла — только текст;
- проверить на экране: после новой отправки в карточке «Последнее отправленное» видна картинка.
