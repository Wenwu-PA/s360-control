## Поведение
- **Окно 960×640:** при ширине меньше 1100 px три графика заменяются вкладками компонентов; один график на всю ширину, точный ввод под ним; прокрутка только в области содержимого; нижняя плашка статуса и главная кнопка закреплены. LCD: предпросмотр сжимается до 168×224, настройки справа; яркость и выключатель — одна строка под выбором режима; при раскрытии дополнительных параметров прокручивается содержимое, «Загрузить» остаётся внизу.
- **Редактор кривых (QPainter):** три канала — радиатор, водоблок, помпа. Выбор компактного графика переносит его в большой редактор и открывает четыре числовые пары. Минимум помпы 60% ограничивается в координатах мыши и в поле ввода, без сообщения. Температуры строго возрастают, мощность не убывает. Точка 5 px, активная 7 px, стрелки меняют на 1, подсказка «48° · 21%». Линия ломаная, без интерполяции данных (сглаживание только для отрисовки). Сетка слабее линии; числа оси и единицы разнесены.
- **Медиа и передача:** «Настроить обрезку» открывает рамку в предпросмотре. В дополнительных параметрах: фон прозрачности, FPS, длительность, подрезка края, поворот самого экрана. Масштаб: заполнить / вписать / растянуть. Яркость 0–100 и выключатель — запрошенные значения, не прочитанные с устройства. Отправка идёт в рабочем потоке; на время отправки блокируются редактирование и повторный запуск, доступна «Остановить». После остановки или USB-ошибки результат неизвестен. Повторная отправка — через диалог. По завершении пишем «Отправлено», никогда «Применено».
- **Данные:** 48 °C, globe.gif, 8,95 с, точки профиля — примеры заполненного состояния. Нет данных → «—». Готовые кривые не выдумывать. Нет RPM, погоды, баннера, истории. Помощь рядом со статусом — одна строка.
- **Qt:** QStackedWidget для вкладок; QGridLayout/QSplitter для ширины; QScrollArea только для содержимого; QSlider и спинбоксы с клавиатурой; предпросмотр 3:4. Не переносить пиксельные координаты из Figma — layouts и minimumSize.

## Общий каркас экрана
Заголовок «MEG CoreLiquid S360», вкладки Обзор / LCD-дисплей / Охлаждение, заголовок страницы, область содержимого, **нижняя полоса**: слева плашка состояния (точка + слово) и одна строка пояснения, справа главное действие экрана.
